## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/AkmalDoghar/portfolio.git
```

Move into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
